**Institutional Agility | Infrastructure-as-Code | SSoT Integrity**

## Repository Structure
- **_SSOT_ENGINE/**: DNA of the department. Contains PAGA, ACSM, and AI standards.
- **_SYSTEM_LOGIC/**: The Brain. Contains the Mission Loop, ID Standards, and Templates.
- **COURSES/**: The Scaffolds. Student-facing modules for 101, 150, 245, and 265.

## Self-Healing Protocol
1. **Detect**: Identify "Instructional Drift" or scaffold failures in student performance.
2. **Patch**: Apply logic hardening to the global files in _SSOT_ENGINE or _SYSTEM_LOGIC.
3. **Propagate**: Updates flow through to the COURSES scaffolds automatically.
